# Before launch

- [ ] Supabase RLS enabled (included in schema.sql)
- [ ] Service role key only in Vercel server environment
- [ ] OpenAI key only on server
- [ ] Stripe webhook signature verification enabled
- [ ] HTTPS/custom domain enabled in Vercel
- [ ] MFA enabled on GitHub, Vercel, Supabase and Stripe
- [ ] Supabase production backups/PITR enabled where available
- [ ] Backup restore test completed
- [ ] Stripe test purchase and cancellation tested
- [ ] Login, logout and email verification tested
- [ ] Rate limiting/WAF enabled through your production edge/provider before opening the AI API to large public traffic
- [ ] Privacy Policy, Terms, refund/cancellation and AI-use disclosures published
- [ ] Ad network policy/consent requirements checked before showing personalized ads
